# plataforma-tributaria
Sistema multiagentes em Python para apoiar rotinas de um analista tributário (apuração, obrigações, planejamento fiscal)  
Plataforma com múltiplos agentes de IA para automatizar tarefas de um analista tributário, construída em Python com orquestração própria e API do claude
# Motivação
O projeto nasceu de um problema real: apoiar o trabalho diário de um(a) analista tributário(a), que lida constantemente com cálculo de tributos, controle de prazos de obrigação acessórios, acompanhamento de mudanças na legislação e planejamento tributário. Em vez de um único chatbot genérico, a proposta é dividir essas responsabilidades entre agentes especializados, coordenados por um orquestrador
